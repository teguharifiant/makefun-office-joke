A one-line joke about office life — the sort of line you send a colleague after a meeting that should have been an email — built by an AI agent for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-liner to `out/entry.txt` (UTF-8, 1–200 characters, a single line).
